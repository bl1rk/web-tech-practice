Программа тренировок: 4-дневный сплит (Верх/Низ)
День недели Группа мышц Упражнение Подходы x Повторения
Понедельник Верх: Спина, Грудь, Плечи Подтягивания 3 x 8-10
Тяга Т-грифа 3 x 8-10
Горизонтальная тяга в блоке 2 x 8-10
Жим гантелей лежа 3 x 6-8
Сведение рук в тренажере (Бабочка) 2 x 6-8
Махи гантелями в стороны 3 x 8-10
Жим сидя в тренажере (на плечи) 2 x 6-8
Вторник Низ + Руки (Ноги, Бицепс, Трицепс) Жим ногами в тренажере 3 x 8-10
Разгибание ног сидя 2 x 8-10
Сгибание ног в тренажере 3 x 8-10
Сгибания рук "Паук" (Spider Curls) 3 x 8-10
Сгибания рук хватом "Молоток" 2 x 6-8
Разгибание рук в блоке (Трицепс) 3 x 8-10
Французский жим из-за головы 2 x 6-8
Четверг Верх: Спина, Грудь, Плечи Вертикальная тяга блока 3 x 8-10
Горизонтальная тяга в блоке 3 x 8-10
Отжимания на брусьях 3 x 8-10
Сведение рук в тренажере (Бабочка) 3 x 8-10
Тяга к подбородку (Протяжка) 3 x 8-10
Махи в кроссовере на заднюю дельту 2 x 8-10
Пятница Низ + Руки (Ноги, Бицепс, Трицепс) Жим ногами в тренажере 3 x 8-10
Разгибание ног сидя 2 x 8-10
Сгибание ног в тренажере 3 x 8-10
Подъем гантелей на бицепс 3 x 8-10
Подъем на бицепс в кроссовере 2 x 8-10
Разгибание рук в блоке (Трицепс) 3 x 8-10
Разгибание с гантелью из-за головы 3 x 8-10
Итого: 4 тренировки в неделю. Для максимальной гипертрофии соблюдайте принципы прогрессивной перегрузки и поддерживайте восстановление (протеин, креатин, сон).
